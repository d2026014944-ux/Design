# ✅ Checklist de Apresentação de Projetos

> Use este checklist antes de publicar ou compartilhar qualquer projeto do portfólio. Ele garante qualidade, consistência e profissionalismo em cada entrega.

---

## 🗂 Checklist Geral do Repositório

### Configuração inicial
- [ ] Nome do repositório em `kebab-case` e descritivo (ex: `app-saude-redesign`)
- [ ] Descrição do repositório preenchida no GitHub
- [ ] Social Preview configurado (imagem 1280 × 640px)
- [ ] Tópicos/tags do repositório preenchidos (ex: `ui-ux`, `figma`, `case-study`)
- [ ] Repositório com visibilidade correta (público para portfólio)

### Estrutura de arquivos
- [ ] `README.md` presente e completo
- [ ] Pasta `assets/` com imagens organizadas
- [ ] Pasta `prototypes/` com links ou arquivos de protótipo
- [ ] Pasta `deliverables/` com entregáveis finais
- [ ] Nomes de arquivos em `kebab-case` sem acentos ou espaços

---

## 📄 Checklist do README de Cada Projeto

### Cabeçalho
- [ ] Título claro do projeto
- [ ] Categoria (UI/UX, Branding ou Visual Design)
- [ ] Link do protótipo navegável **no topo** do documento
- [ ] Badges de ferramentas utilizadas
- [ ] Período e duração do projeto

### Corpo do case
- [ ] **Contexto** — Situação inicial e cliente descritos
- [ ] **Problema** — Declaração clara com dados de suporte
- [ ] **Objetivos** — Metas de negócio e do usuário listadas
- [ ] **Pesquisa** — Métodos e principais insights documentados
- [ ] **Processo** — Wireframes, rascunhos e fluxos incluídos
- [ ] **Solução** — Telas finais com justificativas de decisão
- [ ] **Resultados** — Métricas antes/depois quando disponíveis
- [ ] **Aprendizados** — Reflexão honesta sobre o projeto

### Fechamento
- [ ] **Call to Action** — Convite para feedback ou contato
- [ ] Links para redes sociais/portfólio
- [ ] Créditos (se colaborativo)

---

## 🎨 Checklist Visual

### Imagens e mockups
- [ ] Capa do projeto criada (dimensões corretas por plataforma)
- [ ] Mockups em alta resolução (mínimo 1920px de largura)
- [ ] Screenshots legíveis e sem elementos cortados
- [ ] Imagens de processo incluídas (wireframes, sketches, fluxogramas)
- [ ] Consistência de estilo visual nas imagens

### Design System do projeto
- [ ] Paleta de cores documentada com códigos HEX
- [ ] Tipografia listada (família, pesos, tamanhos)
- [ ] Espaçamento base e grid definidos
- [ ] Componentes principais descritos

---

## 🔗 Checklist de Links e Acessibilidade

- [ ] Link do Figma/Adobe XD funcionando e com acesso liberado para visualização
- [ ] Imagens com texto alternativo (alt text) nos READMEs
- [ ] Links internos do README funcionando corretamente
- [ ] Nenhum link quebrado no documento

---

## 📊 Critérios de Publicação

Antes de publicar, o projeto deve atender **pelo menos** estes critérios mínimos:

| Critério | Mínimo aceitável |
|---|---|
| Contexto e problema | ✅ Obrigatório |
| Pelo menos 1 wireframe ou rascunho | ✅ Obrigatório |
| Telas finais (mockup ou screenshot) | ✅ Obrigatório |
| Link de protótipo ou entregável | ✅ Obrigatório |
| Call to Action | ✅ Obrigatório |
| Resultados ou aprendizados | ⭐ Recomendado |
| Pesquisa com usuários documentada | ⭐ Recomendado |
| Métricas de impacto | ⭐ Desejável |

- 📧 [seu@email.com](mailto:seu@email.com)
