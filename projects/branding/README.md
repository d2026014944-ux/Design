# Branding Projects

This folder contains branding and visual identity case studies — logo design, brand systems, style guides, and brand strategy.

## How to add a project

1. Copy the [`_template/`](../_template/) folder to this directory
2. Rename it with your project name in `kebab-case` (e.g., `startup-brand-identity`)
3. Fill in the `README.md` following the case study structure
4. Add your assets, prototypes, and deliverables to their respective folders
