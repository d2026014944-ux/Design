# Visual Design Projects

This folder contains visual design projects — graphic design, illustrations, motion graphics, social media kits, and print pieces.

## How to add a project

1. Copy the [`_template/`](../_template/) folder to this directory
2. Rename it with your project name in `kebab-case` (e.g., `social-media-campaign`)
3. Fill in the `README.md` following the case study structure
4. Add your assets, prototypes, and deliverables to their respective folders
