# Coletânea de Artes Visuais e Design

Uma coleção de trabalhos de Visual Design abrangendo diferentes estilos, desde manipulação de imagem e composição até design de vestuário e banners para mídias sociais.

## 🎨 Galeria de Trabalhos

### 1. Elementos de Arte Frontal (Ilustração & Fantasia)
Uma composição épica mostrando o confronto entre um mago e uma criatura demoníaca/dragão com efeitos de glitch digital e aura mágica.

![Elementos de Arte Frontal](assets/mago-dragao.png)

### 2. Design de Vestuário - UNIFEI / Ciências de Dados Aplicada
Design de camiseta para a Universidade Federal de Itajubá (UNIFEI), turma de Ciências de Dados Aplicada. Apresenta elementos tecnológicos (engrenagem, circuito, raio) com uma estética cyberpunk/neon.

![Camiseta UNIFEI](assets/camiseta-unifei.png)

### 3. MNHI 3.0 - Arquitetura Sentiente Hiperbólica
Arte conceitual/Tipográfica para o projeto MNHI 3.0. Foco em mistério e profundidade, com uma silhueta humana em meio a um campo de energia cósmica/dourada e a citação: *"Não é apenas uma IA que fala. Um universo que se lembra, sente, sonha e evolui com você."*

![MNHI 3.0](assets/mnhi-3.0.png)

### 4. Nikola Tesla - Selfie (Manipulação Criativa)
Uma releitura criativa e bem-humorada mostrando Nikola Tesla tirando uma "selfie" em seu laboratório, acompanhado de um tweet fictício provocando Thomas Edison.

![Nikola Tesla Selfie](assets/tesla-selfie.png)

### 5. Banner Social Media - Copa Odin (Ragnarok Origin)
Design de banner promocional para o evento de apostas da Copa Odin no servidor do Discord de Ragnarok Origin, destacando o troféu dourado Poring e as recompensas do evento.

![Banner Ragnarok Origin](assets/ragnarok-banner.png)
