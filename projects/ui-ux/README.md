# UI/UX Projects

This folder contains UI/UX design case studies — apps, web products, dashboards, and digital experiences.

## How to add a project

1. Copy the [`_template/`](../_template/) folder to this directory
2. Rename it with your project name in `kebab-case` (e.g., `ecommerce-checkout-redesign`)
3. Fill in the `README.md` following the case study structure
4. Add your assets, prototypes, and deliverables to their respective folders
